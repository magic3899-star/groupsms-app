# 단체문자

모임 공지 문자를 한 번에 보내는 앱입니다.
폰 주소록에서 **그룹을 고르면 각자 이름을 넣어 따로따로** 보내줍니다.

<br>

## 📱 설치하기

### 👉 [**여기를 눌러 앱 내려받기**](https://github.com/magic3899-star/groupsms-app/releases/latest/download/groupsms.apk)

**폰(안드로이드)에서** 위 글씨를 누르면 파일이 내려받아집니다.

<br>

내려받은 뒤 이렇게 하시면 됩니다.

1. 내려받은 **`groupsms.apk`** 파일을 누릅니다
2. **"이 출처의 앱 설치 허용"** 창이 뜨면 → **허용**
3. **"기기에 해를 끼칠 수 있습니다"** 경고가 뜨면 → **무시하고 설치**
4. 설치 → **열기**

> 2번과 3번은 구글 플레이스토어를 안 거친 앱이라 안드로이드가 항상 물어보는 것입니다. 정상입니다.

안드로이드 8.0 이상에서 됩니다. 아이폰은 안 됩니다.

<br>

## ✅ 처음 한 번만 해두세요

앱을 열고 **설정** 탭에서 **내 이름**을 넣어주세요.
문자에 `{내이름}` 자리가 그 이름으로 바뀝니다.

<br>

## 📨 쓰는 법

1. **누구에게 보낼까요?** → `주소록에서 고르기` → 그룹을 누르면 그 그룹 사람들이 나옵니다
2. **무슨 내용을 보낼까요?** → 내용을 씁니다. `{이름}`을 넣으면 **받는 분마다 각자 이름**으로 바뀝니다
3. **이렇게 나갑니다** → 실제로 나갈 문자를 미리 봅니다
4. **보내기**

예를 들어 이렇게 쓰고 10명에게 보내면

```
{이름} 님
{내이름}입니다.

이번 모임 안내드립니다.
```

김영희 님께는 `김영희 님`, 박민지 님께는 `박민지 님` 으로 각자 이름이 들어가서 나갑니다.

<br>

## ⏰ 예약해서 보내기

내용을 다 쓴 뒤 아래 **`나중에 보내기 (예약)`** 를 누르면 달력이 뜹니다.

- **월** 은 `‹` `›`, **년** 은 `«` `»` 로 넘깁니다
- 날짜를 고르고 아래에서 오전/오후와 시간을 맞춥니다
- 예약한 문자는 **보낸 내역** 탭 맨 위에 나오고, 거기서 취소할 수 있습니다
- 폰을 껐다 켜도 예약은 그대로 살아 있습니다

## 📋 명단 붙여넣기

받는 사람 고르기 화면의 **`명단 붙여넣어 한번에 찾기`** 에 이름 목록을 통째로 붙여넣으면 주소록에서 한 번에 찾아 넣어줍니다. 줄바꿈·쉼표·띄어쓰기 아무거나 됩니다. 전화번호로도 찾습니다.

## 🔄 업데이트

앱을 켜면 새 버전이 있는지 알아서 확인합니다.
알림이 뜨면 **`지금 받기`** → **`설치`** 두 번만 누르면 됩니다.

설정 탭의 **`지금 확인하기`** 로 직접 확인할 수도 있습니다.

<br>

## ℹ️ 안내

- 문자를 보내기 위해 **문자 권한**, 받는 사람을 고르기 위해 **주소록 권한**을 사용합니다.
- **연락처는 앱에 저장하지 않습니다.** 폰에서 그때그때 읽기만 하고, 밖으로 보내지 않습니다.
- 문자는 통신사를 통해 실제로 나가므로 **문자 요금이 부과됩니다.** 글이 70자를 넘으면 여러 건으로 나뉘어 요금도 그만큼 나옵니다.
- 앱 화면 아래에 쿠팡 파트너스 배너가 표시되며, 이에 따른 일정액의 수수료를 제공받습니다.
