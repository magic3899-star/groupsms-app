# 단체문자

폰 주소록 그룹을 골라, 각자 이름을 넣은 문자를 한 번에 보내는 안드로이드 앱입니다.
지인 배포용이라 플레이스토어에는 올리지 않습니다.

## 설치

[최신 버전 내려받기](https://github.com/magic3899-star/groupsms-app/releases/latest)

1. 받은 `.apk` 파일을 누릅니다
2. "이 출처의 앱 설치 허용" → 허용
3. Play Protect 경고가 뜨면 "자세히" → "무시하고 설치"

Android 8.0 이상에서 동작합니다.

## 업데이트

앱을 켜면 새 버전이 있는지 자동으로 확인합니다.
알림이 뜨면 [지금 받기] → [설치] 두 번만 누르면 됩니다.
설정 탭의 [지금 확인하기]로 직접 확인할 수도 있습니다.

## 안내

- 이 앱은 문자 발송을 위해 문자 권한, 받는 사람을 고르기 위해 주소록 권한을 사용합니다.
- 연락처는 앱에 저장하지 않고 폰에서 그때그때 읽습니다. 외부로 전송하지 않습니다.
- 앱 화면 아래에 쿠팡 파트너스 배너가 표시되며, 이에 따른 일정액의 수수료를 제공받습니다.
